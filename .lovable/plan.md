# Empowering Athletes Legacy website

## Build approach
- Create a cinematic editorial design system using the provided obsidian, ivory, gold, emerald, and legacy green palette, with refined motion and reduced-motion fallbacks.
- Build a shared site frame with accessible desktop and mobile navigation, footer, page transitions, persistent but restrained calls to action, and a polished 404 state.
- Use generated, safe sports documentary imagery stored with the project. No team marks, league branding, or implied affiliations.

## Pages and content
- Build the full Home experience: cinematic hero, manifesto, interactive story video placeholder, problem and response chapter, eight program pillars, athlete pathway, trust standard, ecosystem, clearly labeled goal metrics, supporter placeholders, and final call to action.
- Add substantial route-specific pages for Who We Are, Programs, Athlete Pathway, Impact, Partners, Get Involved, Portal, Contact, Privacy, and Terms.
- Centralize organization copy, program details, sample metrics, people placeholders, navigation, and replaceable media references so future updates are straightforward.

## Forms and measurement
- Add validated forms for contact, athlete interest, partner inquiry, mentor or volunteer interest, portal access, and the Athlete Legacy Blueprint.
- Build the Blueprint modal plus a dedicated landing section, including consent, success states, optional fields, and captured attribution values such as UTM tags, referrer, landing page, time, and source.
- Add a small internal analytics utility for page views, CTA clicks, video plays, submissions, requests, and donation interest. It will be ready to forward events to GA4, Meta Pixel, or another provider later.
- Since no database or authentication service is connected, this release will safely validate and simulate submissions without storing personal data. Portal and donation actions will be clearly marked as request or connection-ready experiences.

## Quality and launch readiness
- Add unique search and social metadata for every public page, Organization structured data, sitemap, and robots preparation for EALegacy.org.
- Optimize imagery and layout for 375px, 768px, and 1440px widths, with keyboard support, accessible labels, lazy loading, touch targets, and no horizontal overflow.
- Verify the central journeys in the running site: navigation, mobile menu, lead capture, video interaction, form validation and success, portal request, and responsive layouts.
